## Цель работы

Разработать настольное приложение на PySide6 для кредитного скоринга. Пользователь вводит данные о заёмщике и кредите и получает прогноз дефолта. По условию работы модель должна выполнять расчёт в фоновом потоке, чтобы окно оставалось отзывчивым.

## Данные и модель

Основой служит задача классификации из [лабораторной работы № 2](https://github.com/IrishinT/Lab_02_PythonForAI). Датасет содержит 2000 синтетических записей. Для прогноза используются семь признаков — возраст, доход, сумма и срок кредита, количество предыдущих кредитов, количество просрочек и трудовой стаж.

Скрипт [train_model.py](train_model.py) обучает нейросеть на 1600 записях и проверяет её на оставшихся 400. На тестовой выборке модель верно определила класс в 66,5 % случаев. F1 для класса «Дефолт» составила 0,4962. Обученная [модель](models/credit_mlp.joblib) включает масштабирование признаков.

## Получение прогноза

Класс `Predictor` загружает сохранённую модель и возвращает класс и его вероятность. Сервис `PredictionService` принимает семь чисел через запятую в порядке признаков из датасета. Например, для строки `20, 96019, 23421, 24, 0, 1, 14` сервис возвращает «Нет дефолта».

## Запуск приложения

В PowerShell из корня проекта (Python 3.12):

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m desktop.main
```

На вкладке «По полям» у каждого признака есть подпись и пример значения. Доход и сумма кредита указываются в одних денежных единицах. На вкладке «Одной строкой» можно вставить семь чисел через запятую в указанном порядке. Нажмите «Предсказать» или Enter для расчёта. Кнопка «Очистить» сбрасывает данные обеих вкладок и результат.

## Фоновый расчёт

При нажатии «Предсказать» окно передаёт введённые данные в `PredictWorker`, который вызывает сервис в отдельном потоке `QThread`. Пока идёт расчёт, окно можно перемещать, а ввод и повторный запуск заблокированы. Рабочий поток отправляет результат сигналом `finished_ok` или сообщение об ошибке сигналом `failed`. Слоты главного окна обновляют подпись, а после завершения потока форма снова доступна.
